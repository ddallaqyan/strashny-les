# ВЫЖИВШИЙ — хоррор на выживание

Вертолёт разбился в лесу. Нужно продержаться **3 дня и 3 ночи**: охотиться на зверей от голода,
избегать твари, охотящейся по ночам, и следить за фонариком.

## Как запустить
1. Откройте папку `vertolet-survival` в **Visual Studio Code**.
2. Откройте `index.html` и запустите его в браузере (правой кнопкой → "Open with Live Server",
   либо просто дважды кликните по файлу — он откроется в браузере как обычная веб-страница).
   Игра полностью самодостаточна — интернет не требуется.

## Управление
- **WASD** / стрелки — движение
- **Мышь** — направление взгляда и луча фонарика
- **F** — включить/выключить фонарик (садится батарея, включённый привлекает тварь издалека)
- **ЛКМ** или **Пробел** — удар топором (по зверю — еда, по твари — отпугнуть)

## Механики
- Здоровье, голод и батарея фонарика.
- День/ночь по 3 цикла — тварь появляется только ночью, каждую следующую ночь она быстрее и опаснее.
- Деревья блокируют движение (и обзор твари), звери разбегаются и снова появляются через время.
